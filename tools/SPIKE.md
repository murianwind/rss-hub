# 시험(스파이크) 실행 안내

## 이게 무엇인가

설계에서 "아마 이럴 것이다"라고 가정한 부분을 **실제 서비스로 한 번 해보고 확인**하는 시험입니다.
요약과 발송을 본격적으로 만들기 전에 해야 나중에 크게 고치는 일을 막을 수 있습니다.

| 시험 | 확인하는 것 | 필요한 것 |
|---|---|---|
| **S1 OpenRouter** | 요약 품질이 나쁜 원인이 "모델이 생각하는 데 글자 수를 다 써서 답이 잘리는 것"인지, 그리고 생각을 끄거나 JSON 형식을 강제하는 방법이 통하는지 | OpenRouter 키 |
| **S2 Discord** | 너무 빨리 보내면 Discord가 뭐라고 답하는지, 메시지 길이 한도, 보낸 메시지를 지울 수 있는지, 삭제된 웹훅으로 보내면 어떤 오류가 나는지 | **시험용** 채널과 웹훅 |

## 안전에 대해

- 스크립트는 **파이썬 표준 기능만** 씁니다. 설치할 것이 없습니다.
- 키와 웹훅 주소는 **실행할 때 직접 입력**합니다. 입력해도 화면에 보이지 않고, 파일에 저장하지 않습니다.
- 결과 보고서에는 키와 웹훅 주소가 **들어가지 않습니다.** 만들 때 한 번 더 걸러 냅니다.
- S2는 **운영 채널이 아니라 시험용 채널**에만 쓰세요. 시험 메시지를 여러 개 보내고, 끝나면 스스로 지웁니다.
- 대화창에는 **보고서만** 붙여넣으세요. 키나 웹훅 주소를 붙여넣지 마세요.

## 준비

- 파이썬 3.9 이상(`python --version`으로 확인). 기존 Hermes 스크립트가 파이썬이라 이미 있을 겁니다.
- `tools/spike.py` 파일 하나만 있으면 됩니다.

## 키 정보만 확인 (호출 한도를 쓰지 않음, 10초)

하루 호출 한도 같은 키 정보만 보고 싶을 때:

```
python spike.py key
```

채팅 호출이 없어서 무료 모델의 하루 호출 한도를 쓰지 않습니다. 결과를 붙여넣으실 때 계정 번호 같은 식별자는 보고서에 들어가지 않습니다(항목 이름만 나옵니다).

## S1: OpenRouter (약 5~10분)

PowerShell에서 `spike.py`가 있는 폴더로 이동한 뒤:

```
python spike.py openrouter
```

1. OpenRouter 키를 입력합니다(화면에 보이지 않습니다).
2. **사전 확인**: 후보 모델마다 짧은 호출을 1번씩 보내서 **응답하는 모델만 골라 본 시험에 씁니다.** 응답하지 않는 모델(예: 30초 안에 답이 없음)은 **이유와 함께 제외**하고 보고서에 기록합니다. 키나 잔액 문제면 이유를 알려 주고 바로 멈춥니다.
   이 단계는 모델 응답 속도를 확인하는 것이기도 합니다. 무료 모델이 너무 느리면 그 자체가 중요한 발견입니다(지금 쓰는 스크립트는 30초 안에 답이 없으면 다음 모델로 넘어갑니다).
3. 시험 계획이 나옵니다. 예: `모델 4개 × 방식 4개 × 글 2개 = 호출 최대 32회`
   **무료 모델의 하루 호출 한도를 그만큼까지 씁니다.** 결제 이력이 없으면 하루 한도가 50회라서 32회는 큰 부분입니다. 걱정되면 `n`을 입력해 취소하고 아래처럼 줄여서 다시 실행하세요.

```
python spike.py openrouter --max-models 2
python spike.py openrouter --max-models 2 --variants A,C,D
```

4. `y`를 입력하면 시작합니다. 호출 사이에 4초씩 쉽니다. 한 줄씩 결과가 나오고, 실패하면 **그 줄에 이유가 바로 나옵니다.**
   - 같은 이유로 3번 연속 실패하면 그 모델은 건너뜁니다(헛된 호출을 줄이려는 것입니다).
   - **언제든 `Ctrl+C`로 멈출 수 있고, 그때까지의 결과로 보고서를 만듭니다.**
5. 끝나면 보고서가 화면에 나오고 `spike-report-openrouter.txt`로도 저장됩니다. **보고서 전체를 대화창에 붙여넣어 주세요.**

### 시험하는 네 가지 방식

| 방식 | 내용 |
|---|---|
| A | 지금 쓰는 방식 그대로(기존 프롬프트, 글자 수 350) |
| B | 새 프롬프트로 JSON 답변 요청, 글자 수 700 |
| C | B + 생각하는 기능 끄기 |
| D | C + JSON 형식 강제 |

"A는 자주 실패하고 C나 D는 통과한다"는 결과가 나오면, 원인이 모델 자체가 아니라 호출 방식이라는 뜻입니다.

## S2: Discord (약 3분)

1. Discord에서 **시험용 채널**을 하나 만듭니다.
2. 그 채널의 설정 → 연동 → 웹후크 → 새 웹후크 → **웹후크 URL 복사**.
3. 이 주소를 **메모장에 따로 붙여 두세요**(뒤의 4번 단계에서 한 번 더 씁니다).

```
python spike.py discord
```

4. 웹훅 주소를 입력하면(화면에 보이지 않습니다) 시험 채널에 메시지가 여러 개 올라왔다가 사라집니다. **첫 메시지의 모양**(굵은 글씨, "글 읽기" 링크)이 어떻게 보이는지 눈으로 확인해 주세요.
5. 보고서를 붙여넣어 주세요(`spike-report-discord.txt`로도 저장됩니다).

### 삭제된 웹훅 시험(선택, 1분)

1. Discord에서 방금 쓴 시험 웹훅을 **삭제**합니다.
2. 메모장에 적어 둔 주소로:

```
python spike.py discord-deleted
```

3. 보고서를 붙여넣어 주세요. 삭제된 웹훅에 보냈을 때 Discord가 어떤 오류를 주는지 확인하는 시험입니다.

## 문제가 생기면

| 증상 | 해결 |
|---|---|
| `python`을 찾을 수 없음 | `py spike.py openrouter`로 실행해 보세요 |
| 모델 목록이 비어 있음 | 키가 올바른지, 인터넷 연결을 확인하세요 |
| `HTTP 401` | 키가 틀렸습니다 |
| `HTTP 402` | OpenRouter 계정의 잔액이 음수입니다 |
| `HTTP 404`와 `data policy` | OpenRouter의 개인정보 설정 때문에 무료 모델을 못 씁니다. https://openrouter.ai/settings/privacy 에서 무료 모델 관련 항목을 확인하세요 |
| `HTTP 429`가 많음 | 하루 한도에 걸렸거나 제공자가 붐빕니다. 내일 다시 하거나 `--max-models 1`로 줄이세요 |
| 사전 확인에서 `시간 초과`로 제외됨 | 무료 모델이 붐비거나 멈춘 것입니다. 사전 확인은 모델당 최대 30초 기다립니다(`--preflight-timeout 60`으로 늘릴 수 있습니다). 모든 모델이 제외되면 나중에 다시 하세요 |
| 본 시험 중 호출이 오래 걸림 | 한 호출당 최대 60초까지 기다립니다. `--timeout 30`으로 줄이거나 나중에 다시 하세요 |
| 한글이 깨져 보임 | PowerShell에서 `chcp 65001`을 먼저 실행하세요. 저장된 텍스트 파일은 정상입니다 |
