# 점검 기록: 사용 피드백 4차

사용자 요청 3개: (1) 목록을 끊김 없이 스크롤되게 하거나 이전/다음 버튼을 예쁘게, (2) 사이트 목록 상단 제목을 누르면 그 사이트로 이동, (3) 읽지 않은 글이 있는 사이트는 진하게, 없는 사이트는 연하게.

## 1. 결과 요약

| 항목 | 결과 |
|---|---|
| 테스트 | 3230개 통과(전달본에 덮어쓴 사본에서 확인) |
| 린트/포맷, `mypy --strict`, `vulture` | 모두 통과 |
| 시나리오 | VPL-08~11 추가. 모두 `.feature` 그대로 연결 |
| 변이 확인 | 새 로직 6개를 모두 잡는다 |
| 실제 크롬 | 글 71개 목록에서 스크롤 3번 만에 30→60→71개로 이어 붙고 "마지막 글입니다" 표시, 제목 링크가 새 창으로 열림(목록은 그대로), 사이트별 굵기와 불투명도(700/1 대 400/0.55), 스크립트를 끈 상태의 "2 / 3"과 이전/다음 버튼, 보안 정책 위반과 페이지 오류 없음 |

## 2. 항목별 결과

| # | 요청 | 결과 |
|---|---|---|
| 1 | 끊김 없는 스크롤 또는 보기 좋은 이전/다음 | 둘 다 했다. 스크립트가 있으면 끝에 다가갈 때(800px 전) 다음 쪽을 가져와 이어 붙인다. 스크립트가 없거나 이어 붙이기가 실패하면 "2 / 3" 쪽 표시와 알약 모양의 이전/다음 버튼으로 돌아간다 |
| 2 | 제목을 누르면 사이트로 | 사이트별 목록에서만. 피드가 알려 준 사이트 주소로, 없으면 피드 주소의 사이트 맨 앞으로 새 창에서 연다 |
| 3 | 진하게/연하게 | 사이드바의 사이트(RSS 피드 구역과 카테고리 안의 같은 사이트 모두). 읽거나 새로 수집될 때 화면을 다시 불러오지 않고 바뀐다 |

## 3. 설계 결정(확인이 필요하면 알려 주세요)

| # | 결정 |
|---|---|
| 1 | 이어 보기는 다음 쪽 전체 화면을 받아 글 카드만 떼어 붙이는 방식이라 서버 쪽 변경이 없다. 받아 온 카드의 읽음 처리, 북마크, 자동 읽음은 그대로 동작한다 |
| 2 | 제목 링크는 사이트별 목록에만 있다(전체 글, 북마크, 카테고리, 주제 목록은 가리킬 사이트가 하나가 아니다) |
| 3 | 진하게/연하게는 **사이트 행에만** 적용했다. 카테고리와 주제 행은 지금처럼 둔다(원하시면 같은 규칙으로 맞출 수 있다) |

## 4. 작업 중 발견하고 고친 것

| # | 내용 | 조치 |
|---|---|---|
| 1 | **사이트 주소에 계정 정보가 든 주소(`https://user:pw@evil...`)가 있으면 제목 링크로 그대로 나갈 수 있었다.** 기존 `is_web_link`는 http(s) 방식만 확인한다. 시험이 잡았다 | 사이트 주소는 계정 정보가 없는 http(s)만 쓰고, 아니면 피드 주소의 사이트 맨 앞으로 대체한다 |
| 2 | 쪽 이동의 문구(`← 이전`, `다음 →`)를 단언하던 기존 시험과 BDD 단계 3곳이 새 마크업에 걸렸다 | 마크업(`data-prev`, `data-next`, 쪽 표시)으로 단언하도록 수정 |
| 3 | 사이트 주소를 고르는 규칙의 "아무것도 쓸 수 없다" 분기가 시험되지 않았다(커버리지 확인에서 발견) | 규칙을 직접 시험하는 매개변수 시험 추가 |

**과정에 대한 정직한 기록**: 화면과 스크립트는 구현을 먼저 했고 시험을 나중에 썼다. `app.js`의 이어 보기 동작은 자동 시험이 없고(사용자 결정) 크롬으로만 확인했다. 시험은 스크립트가 필요한 마크업과 문자열이 있는지만 확인한다.

## 5. 알려진 한계

| # | 내용 |
|---|---|
| 1 | 이어 붙은 뒤에는 주소가 바뀌지 않는다. 새로고침하면 처음 쪽으로 돌아가고, 글을 열었다가 돌아오면 그 글이 있던 쪽의 목록으로 돌아간다 |
| 2 | 이어 보기에서 검색어나 필터를 바꾸면 목록을 새로 불러온다(처음 쪽부터) |
| 3 | 전체 커버리지는 이번에 다시 합쳐서 재지 못했다. 바뀐 `reader` 모듈은 마지막 시험 추가 뒤 해당 줄이 채워졌음을 확인했고, 나머지 모듈은 바뀐 것이 없다 |
| 4 | Docker 이미지는 이 환경에서 직접 빌드하지 못했다 |
