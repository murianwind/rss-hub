# 점검 기록: 피드 관리 화면(버튼, 카드, 필터)

사용자 요청: (1) 피드 관리의 OPML 가져오기/내보내기/카테고리 관리 버튼을 "목록으로 돌아가기" 버튼 디자인으로, (2) 피드 카드가 쓸데없이 길어 설정, 새로고침, 삭제를 누르기 힘드니 페이지 너비에 따라 카드 너비가 변하게(최소 너비는 내용이 모두 출력되는 값, 긴 제목은 ...로 줄임), (3) 수집 주기(시간당 1, 2, 3회)와 마지막 게시(1주일, 1달, 1년 이내 등) 필터 추가.

## 2. 항목별 결과

| # | 요청 | 결과 |
|---|---|---|
| 1 | 버튼 디자인 | 세 버튼이 글 화면의 "목록으로 돌아가기"와 같은 클래스(`back`)를 쓴다. 크롬에서 계산된 스타일(바탕, 글자색, 높이, 모서리, 굵기, 글자 크기)이 같음을 확인했고, 위쪽 화살표, 아래쪽 화살표, 폴더 아이콘을 붙였다 |
| 2 | 카드 | **원인:** 카드가 한 열로 페이지 전체 너비(최대 760px)를 차지해서 제목 줄의 설정, 새로고침, 삭제 버튼이 카드 맨 오른쪽 끝에 있었고, 본문 영역도 좁게 제한되어 있었다. **조치:** 피드 관리는 넓은 페이지로 바꾸고 카드를 자동 격자(`repeat(auto-fill, minmax(min(100%, 440px), 1fr))`)로 놓았다. 크롬에서 700px는 1열(카드 676px), 1280px는 2열(481px), 1800px는 3열(490px)이고, 카드 안 내용이 넘치거나 가로 스크롤이 생기지 않으며(넘친 카드 0개), 매우 긴 제목은 줄임표로 잘리고 버튼이 카드 안에 있다. 전체 제목은 이름의 말풍선(`title`)으로 본다 |
| 3 | 필터 | 검색 칸 옆에 선택 상자 두 개. **수집 주기**: 시간당 1회, 2회, 3회(3은 3회 이상). **마지막 게시**: 하루, 1주일, 1달(30일), 1년(365일) 이내, 그리고 "1년 넘게 없음"(게시 기록이 없는 피드 포함). 선택하면 바로 적용되고 검색어, 상태 칩과 함께 쓴다. 상태 칩의 개수와 주소도 조건을 따른다 |

## 3. 설계 결정(확인이 필요하면 알려 주세요)

| # | 결정 |
|---|---|
| 1 | 수집 주기 필터는 화면에 보이는 값(스케줄러가 실제로 배정한 횟수)을 기준으로 한다. 활동량으로 원한 횟수(예: 3회 원했지만 용량이 모자라 2회)가 아니다 |
| 2 | 이 서비스의 점검 횟수는 시간당 최대 3회라서 "3회"는 "3회 이상"으로 처리했다 |
| 3 | 요청하신 기간 외에 "하루 이내"와 "1년 넘게 없음"을 더했다(오래 조용한 피드를 정리할 때 쓰기 좋다). 필요 없으면 빼겠다 |
| 4 | 배정 전인 피드(다음 정각에 배정됨)는 수집 주기 필터를 고르면 보이지 않는다 |
| 5 | 카드 최소 너비 440px은 "주소, 수집 주기, 활동량 줄이 줄바꿈으로 모두 보이는 너비"로 정했다. 더 줄이길 원하면 한 값만 바꾸면 된다 |

## 4. 작업 중 발견하고 고친 것

| # | 내용 | 조치 |
|---|---|---|
| 1 | 상태 칩의 주소가 검색어만 이어 가서, 수집 주기와 마지막 게시를 고른 뒤 칩을 누르면 조건이 사라질 뻔했다 | 칩 주소를 서버에서 모든 조건으로 만든다(값의 `/`도 인코딩) |
| 2 | 시험에서 카드를 찾을 때 사이드바에도 같은 이름이 있어 카드 앞 조각이 먼저 잡혔다 | 카드 조각만 보도록 고침 |
| 3 | BDD 단계에서 후보 집합을 잘못 판별해 두 시나리오가 실패했다(단계 코드 오류) | 판별 조건 수정 |
| 4 | `vulture`가 시험에서 쓰지 않는 속성 저장을 지적했다 | 제거 |

**과정에 대한 정직한 기록**: 필터 판정 함수(`_cycle_matches`, `_last_matches`, `_feeds_url`)는 경계값 시험과 함께 만들었고, 화면 배치(격자)는 구현 뒤 크롬에서 측정으로 확인했다. 카드 열 수는 CSS 문자열 시험과 크롬 측정으로만 확인한다(자동 레이아웃 시험은 없다).

## 5. 알려진 한계

- 커버리지: 바꾼 `web/feeds.py`는 모듈별로 측정해 줄과 분기 100%다. **프로젝트 전체 합산은 이번에 다시 하지 못했다.** 이번 변경은 이 모듈과 템플릿, 스타일, 스크립트, 아이콘 두 개뿐이다.
