## 3. 웹페이지 구독 설계

| 영역 | 내용 |
|---|---|
| 구독 종류 | 피드에 `kind`(feed, page) 열 추가(마이그레이션 14, 기존 피드는 feed) |
| 글 감지(`domain/page_feed.py`) | 목록 주소 경로 아래의 같은 사이트 링크를 글로 본다(예: 목록 `/Insights/Blog` → `/Insights/Blog/글이름`). 3개 미만이면 같은 상위 경로 링크가 가장 많은 묶음을 쓴다. 메뉴, 푸터, 사이드, 폼, 스크립트 안의 링크, 태그, 분류, 쪽 번호, 작성자, 검색, 이미지와 문서 파일, 다른 사이트, 계정 정보가 든 주소는 뺀다. 최대 50개 |
| 제목과 날짜 | 같은 글의 여러 링크를 합치고 앵커 글자, `title` 속성, `aria-label`, 이미지 설명 중 잘리지 않은 가장 긴 것을 고른다. 앞의 날짜(ISO, 점과 슬래시, 한글, 영어 월 이름)와 분류 이름("Blog:", "Read more:", 모든 글에 공통인 "라벨:")을 뗀다. 날짜는 앵커 글자 앞이나 `<time datetime>`에서 얻는다 |
| 수집(`services/page_source.py`, `collect.py`) | 목록 페이지를 일반 피드와 같은 결과 모양으로 바꿔 기존 점검 흐름에 넣는다(기준선, 오늘 글만, 알림 규칙 동일). 글을 못 찾으면 `NoItems` 실패로 기록한다. 새 글은 글 페이지에서 본문을 뽑아 채운다(한 번에 최대 10개, 이미 본 글은 다시 가져오지 않는다) |
| 날짜 규칙 | 목록에 날짜가 있으면 그 날짜(오늘만 저장), 없으면 가져온 시각(목록 순서를 지킨다) |
| 등록 | 피드가 없고 글이 3개 이상이면 "웹페이지 구독" 후보(글 수, 예시 제목 3개)를 낸다. 등록 직전에 다시 확인한다 |
| 깨졌을 때 | 점검 실패로 기록되어 기존 상태 점이 빨갛게 바뀐다. 피드 설정 패널에서 목록 페이지 주소를 고치면 새 주소의 글 목록을 확인한 뒤 저장한다 |
| 표시 | 피드 관리에 "웹페이지" 배지, 설정 패널 라벨은 "목록 페이지 주소", OPML 내보내기에서는 제외 |

## 4. 작업 중 발견하고 고친 것

| # | 내용 | 조치 |
|---|---|---|
| 1 | 수집 서비스는 "오늘 날짜" 글만 저장한다. 날짜가 없는 목록의 글은 영원히 저장되지 않을 뻔했다 | 날짜가 없는 글은 가져온 시각으로 친다(목록 순서를 지키도록 1ms씩 낮춘다) |
| 2 | 글 페이지 견본에 같은 문단을 여러 번 넣었더니 전문 정리의 "같은 문단은 한 번만" 규칙으로 본문이 비었다 | 시험 견본의 문단을 서로 다르게 고침(규칙은 의도대로) |
| 3 | 후보로 낼 최소 글 수 확인이 중복 같아 보였으나, 제목을 쓸 수 없는 링크가 걸러지면 글이 3개 미만이 될 수 있어 필요한 확인이었다 | 그 경우의 시험 추가(처음에 변이로 살아남았음) |
| 4 | 크롬 확인 스크립트가 사이드바 점의 클래스를 `dot`으로 잘못 가정했다(실제는 `state-dot`) | 스크립트 수정(제품 문제는 아님) |

**과정에 대한 정직한 기록**: 글 감지, 수집원, 등록 서비스는 시험을 나중에 썼다(구현을 먼저 했다). 대신 변이 확인으로 시험의 구멍을 찾아 메웠다. 크롬 확인은 실제 사이트가 아니라 파일로 조작하는 가짜 사이트로 했다.

## 5. 알려진 한계

| # | 내용 |
|---|---|
| 1 | **comscore 블로그 같은 실제 사이트의 HTML로는 확인하지 못했다.** 내가 받은 것은 변환된 본문이라, 그 구조를 흉내 낸 견본으로 감지를 시험했다. 배포 후 "피드 추가"에서 확인하면 글 수와 예시 제목이 바로 보인다 |

| 3 | 쪽 번호를 따라가지 않아 첫 쪽의 글만 본다 |
| 4 | 날짜는 ISO, 점이나 슬래시 구분, 한글, 영어 월 이름만 인식한다(`7/29/2026` 같은 모호한 형식은 무시) |
| 5 | 첫 점검 때 보관하는 최근 글(뷰어용)은 본문이 비어 있고, 열면 전문 보기로 가져온다 |
| 6 | 글 감지는 휴리스틱이라 사이트마다 달라질 수 있다. 잘못 잡히면 후보 화면의 예시 제목에서 먼저 보인다 |
| 7 | Docker 이미지는 이 환경에서 직접 빌드하지 못했다 |
